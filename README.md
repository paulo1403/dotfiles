# dotfiles

Personal dotfiles for **Arch Linux + Hyprland**, managed with [GNU stow](https://www.gnu.org/software/stow/).

## Stack

- **OS:** Arch Linux
- **Compositor:** Hyprland (config: `~/.config/hypr/hyprland.lua`)
- **Shell/bar/wallpaper:** [wayle](https://github.com/wayle-shell/wayle) — wallpaper cycling + dynamic theming via **matugen**
- **Terminal:** ghostty (colors auto-generated by matugen into `~/.config/ghostty/matugen-theme.conf`)
- **Theme:** Catppuccin
  - Wallpaper-driven UI (wayle bar, gtk, ghostty, cava, btop) follows the current wallpaper through matugen → **Mocha** palette.
  - Static accents in this repo use **Macchiato (Teal)** for apps matugen does not touch (rofi, starship, fastfetch, cursor).

## Structure

```
dotfiles/
├── rofi/            # .config/rofi — launcher (catppuccin-macchiato theme)
│   ├── config.rasi
│   └── themes/catppuccin-macchiato.rasi
├── starship/        # .config/starship.toml — shell prompt (macchiato)
├── fastfetch/       # .config/fastfetch/config.jsonc — system fetch
├── cava/            # .config/cava/shaders — visualizer shaders
└── cursors/         # .icons — Catppuccin-Macchiato-Teal cursor (X11 + hypr)
```

## Install

```bash
sudo pacman -S stow            # or: yay -S stow
git clone https://github.com/paulo1403/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow -t ~ rofi starship fastfetch cava cursors
```

Each package symlinks its `.config`/`.icons` subtree into your home. Re-run `stow` per package after pulling updates.

## Agent / AI notes

- This repo contains **only curated config** (not a full-home backup). System configs (hyprland.lua, wayle, matugen templates) live in `~/.config` and are managed separately.
- `cursors/` ships two variants: `Catppuccin-Macchiato-Teal-Cursors` (X11/`XCURSOR_THEME`) and `…-Hypr` (hyprcursors). Hyprland uses the `-Hypr` one.
- `rofi/config.rasi` depends on `FiraCode Nerd Font` + `Papirus-Dark` icon theme being installed.
- Dynamic colors (gtk/ghostty/cava/btop) are generated at runtime by matugen on wallpaper change — do not hand-edit those outputs; edit `~/.config/matugen/templates/` instead.
- Default terminal is `ghostty` (`$TERMINAL` + Hyprland `$terminal`). Rofi launches apps via `ghostty`.
